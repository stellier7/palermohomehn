---

Hola — para armar el sitio de **Palermo** (bienes raíces / ventas; no es AirHome), necesito estos datos. Puedes responder en texto o notas de voz.

## Obligatorios

1. **Nombre comercial exacto** (¿Palermo, Palermo Bienes Raíces, Palermo Home HN, otro?)
2. **Eslogan / tagline** (1 línea)
3. **Logo** (PNG o SVG con fondo transparente si se puede)
4. **Qué hace Palermo** (marca con X todo lo que aplique):
   - [ ] Venta de casas/apartamentos
   - [ ] Terrenos / lotes
   - [ ] Proyectos de desarrollo
   - [ ] Corretaje / intermediación
   - [ ] Alquileres de largo plazo
   - [ ] Otro: ___
5. **Zonas de servicio** (ciudades / colonias)
6. **Contacto Palermo** (no el de AirHome si es distinto):
   - WhatsApp:
   - Teléfono:
   - Email:
   - Dirección de oficina (si hay):
7. **3 a 6 propiedades o proyectos destacados**, cada uno con:
   - Nombre / título
   - Precio o “desde”
   - Ubicación
   - Tamaño (m² o varas)
   - Habitaciones / baños (si aplica)
   - 3–5 características clave
   - Fotos (ver lista abajo)

## Deseables

- Bio del dueño o del equipo + años de experiencia
- Testimonios o casos vendidos (con permiso para publicar)
- Redes (Instagram, Facebook, LinkedIn, etc.)
- Colores de marca (o pantones / captura del logo)
- Info de financiamiento o proceso legal / compraventa
- Preguntas frecuentes (3–5) con respuestas
- Confirmación del link AirHome: https://airhomehn.com/ (¿lo mencionamos como “mismo equipo”?)
